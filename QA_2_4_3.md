# QA 2.4.3 — Gemini AI Provider

## Completed checks

- Gemini is the only runtime AI provider reference.
- `GEMINI_API_KEY` is server-only and is not exposed through `VITE_*` variables.
- VELORA AI uses the Gemini Interactions API.
- Default model is `gemini-3.8-flash`, configurable with `GEMINI_MODEL`.
- Chat history is sent as typed user/model interaction steps with `store: false`.
- Response extraction supports both `output_text` and model-output text parts.
- Provider/API errors are converted into a safe user-facing fallback message.
- Existing Hindi/Hinglish, Unicode, emoji and multiline message content is passed through without manual encoding transformations.
- VELORA-specific system instructions cover buyer, seller, listing, search, payment, delivery, moderation, policy and troubleshooting help.
- Secrets are not included in the release archive.
- Production audit: PASS.
- TypeScript parser/syntax scan: PASS.
- ZIP integrity test: PASS.

## Environment limitation

A live Gemini request was not executed because this release environment intentionally contains no production Gemini API key. A real staging deployment should make one authenticated test request after setting `GEMINI_API_KEY`.

A full dependency install/browser build is also deployment-environment work when `node_modules` is not available. The checked-in Playwright suite remains available for that final staging run.
