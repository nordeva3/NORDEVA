# VELORA Marketplace 2.4.4 — Final QA Review

## Scope

- Cross-checked the 2.4.3 Gemini release against this release: 184 files retained; 5 intentional files changed.
- Reviewed application security against OWASP Top 10:2025 / ASVS 5.0 themes, Supabase RLS/grants guidance, Gemini Interactions API, and Playwright testing guidance.

## Changes in 2.4.4

- Gemini Interactions API uses the stable `/v1/interactions` endpoint.
- AI chat localStorage history is schema-validated before reuse, preventing malformed/corrupted browser state from entering the request pipeline.
- AI request rate-limit buckets are bounded to prevent unbounded memory growth from many distinct client identifiers.
- Public `/api/health` no longer discloses which private payment/email/scanner integrations are configured.
- Production audit script checks the stable Gemini endpoint and chat-history validation.
